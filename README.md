# Medical Insurance Cost Prediction

## Project Overview
A Machine Learning project that predicts medical insurance charges using Linear Regression based on personal attributes and lifestyle factors.

## Dataset
The dataset contains information such as age, sex, BMI, number of children, smoking status, region, and medical insurance charges.

## Project Workflow
- Data loading and inspection
- Data cleaning and handling missing values
- Exploratory Data Analysis (EDA)
- Data preprocessing and categorical encoding
- Correlation analysis
- Train-test splitting
- Linear Regression model training
- Model evaluation
- Prediction on new data
- Model saving

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook

## Project Files
- `insurance.csv` – Dataset
- `medical_insurance_cost_prediction.ipynb` – Complete project notebook
- `insurance_model.pkl` – Saved Machine Learning model
- `Medical_Insurance_Cost_Prediction.pdf` – Project documentation

## Objective
To analyze medical insurance data, understand the factors influencing insurance charges, and predict costs using Machine Learning.
